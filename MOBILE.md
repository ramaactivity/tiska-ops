# MOBILE — halaman tim (PWA) & tampilan HP

Pengguna: captain, dapur, driver, gudang, crew — banyak usia 50+, sebagian tidak lancar membaca, HP Android lama.

- Kolom konten maks 480px, bottom navigation maks 4 ikon berlabel, FAB untuk aksi utama bila perlu.
- Target sentuh **≥48px**; jarak antar tombol cukup; maks 2–3 tombol aksi per layar.
- Input ≥16px (cegah zoom iOS); hindari input teks — pakai tombol, pilihan bergambar, 🎤 suara, 📷 foto.
- Safe-area padding (notch, bar navigasi).
- Tabel berubah menjadi kartu di HP.
- Ikon konsisten dengan emoji yang dikenal tim di grup WA: ⏰ jam · 📍 alamat · 🍱 order box · 🥐 snack · 🚐 kendaraan · 👉🏻 tugas · 🌻 bunga · 👥 pax · ✅ selesai · ‼️ update.
- Setiap layar tugas punya tombol **🔊 Dengarkan** (TTS id-ID) dengan teks suara yang ditulis alami.
- Angka penting besar & tebal (jam berangkat, jumlah box).
- Offline: brief & tugas hari ini tersimpan; aksi antre lalu terkirim saat sinyal kembali (tampilkan "menunggu sinyal").
- Ukuran halaman kecil (gambar dikompres, tanpa library berat) — target nyaman di HP 2 GB RAM, 3G.
- Uji wajib: Android murah asli + layar 360px; iPhone mode "Tambahkan ke Layar Utama"; mode hemat baterai.
- Desktop/kantor (owner, sales, accounting) tetap responsif di HP untuk cek cepat (Pustaka Pricelist, status order, persetujuan).
